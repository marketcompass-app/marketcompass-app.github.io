HELP & SUPPORT

Help when you need it.

A few essentials for using MarketCompass, plus a direct way to ask for help.

Getting started

  1. Install MarketCompass from the Chrome Web Store or Microsoft Edge Add-ons.
  2. Open the toolbar Popup, then choose the Dashboard or Widget.
  3. Use Add Assets to build a watchlist. Follow the API key setup guide for the data sources you use.
  4. Refresh the data and review its observation date. Daily and reference sources may not publish on every day.

Set up your three API credentials

For the fullest supported data coverage, configure Tiingo, Finnhub and CoinGecko. Each key is needed for that provider’s feeds, not for every feature of MarketCompass. Provider plans, supported symbols, rate limits and historical coverage still apply in Free and Pro.

  1. Tiingo API token: Create or sign in to your account at Tiingo. Follow Tiingo’s token instructions to copy your personal token. This enables Tiingo daily price/NAV and historical-performance coverage for supported stocks, ETFs and mutual funds.
  2. Finnhub API token: Register with Finnhub, then sign in to the Finnhub dashboard and copy your API key. This enables Finnhub stock/ETF quote coverage. Earnings-calendar and other research features also depend on the access included in your Finnhub plan.
  3. CoinGecko Demo API key: Create or sign in to your CoinGecko account and follow the official Demo API setup guide. Generate a Demo key in the Developer’s Dashboard. The current extension uses the Demo endpoint for cryptocurrency prices and supported historical data. A paid CoinGecko Pro key is not a substitute for a Demo key.

Save the keys in MarketCompass

  1. Open Dashboard → Settings & Sources → Source APIs.
  2. Paste each credential into its matching field: Tiingo API token, Finnhub API token, and CoinGecko Demo API key.
  3. Click Save Source APIs, then Refresh All. Allow queued checks to finish instead of repeatedly clicking Refresh.
  4. Check source diagnostics and observation dates. A saved key does not guarantee that your provider plan includes every symbol, historical period or research endpoint.

Keys stay in local extension storage for that browser profile and are sent to their respective providers to authenticate requests. Never email your keys to support or include them in public screenshots. The Pro license key is separate from these data-provider credentials.

FX reference rates, Treasury yields and several other public-data feeds can work without these keys. Without a key, its specific feeds may be unavailable even if another source supplies some prices.

Frequently asked questions

Does Refresh update the other views?

Views in the same browser profile share data. Refresh All requests a broader update; the more specific refresh buttons update their named data. This is not a reload of the browser window.

Why is a value unavailable or dated?

A source may be delayed, closed, rate-limited, temporarily unavailable or missing historical coverage. Check the observation date and source settings. Use diagnostics if a value remains unavailable after refresh.

Why does the Popup close when I click elsewhere?

The browser closes toolbar popups when they lose focus. Use the Widget or Dashboard for a view that stays open.

Where is my data stored?

In the extension’s local storage for that browser profile. There is no automatic portfolio or watchlist cloud synchronization. Back up important records before changing profiles or removing the extension.

How do I manage Pro?

Open Settings & Sources and Plan & usage. Use the billing management options for subscription changes. Deactivate a browser installation where possible before removing the extension; uninstalling does not cancel a subscription.

Can I place trades?

No. MarketCompass displays financial information and records portfolios; it is not connected to a brokerage and does not execute trades.
